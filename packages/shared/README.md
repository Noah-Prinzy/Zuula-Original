# @zuula/shared

TypeScript types generated from [`apps/api/openapi.yaml`](../../apps/api/openapi.yaml), the P2 API
contract. `src/openapi.ts` is generated by [`openapi-typescript`](https://openapi-ts.dev/) — never
edit it by hand. `src/index.ts` is a thin, hand-written layer of friendlier aliases
(`FactCheckReport`, `Verdict`, `ReviewCase`, …) over the generated `components["schemas"][...]`
shapes, for the types used often enough across `apps/web` and `apps/api` to be worth a short name.

## Regenerate after editing the contract

```bash
cd packages/shared
npm install
npm run generate   # apps/api/openapi.yaml -> src/openapi.ts
npm run typecheck
```

## Status (P2, Step 1)

Not yet wired into `apps/web`'s build — `apps/web` keeps using `apps/web/lib/types/fact-check.ts`
and `apps/web/lib/mock/*` until P3, when the real API replaces the mocks. At that point
`apps/web`'s `lib/types/fact-check.ts` types get replaced by imports from `@zuula/shared`, and this
package should be added to a root npm workspace (there isn't one yet) so `apps/web` can resolve
`@zuula/shared` without a manual `file:` link. Neither change happens in P2 — see the P2 brief,
§1: "Don't change `apps/web` yet."
